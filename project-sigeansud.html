Projet BTS SIO · AP4

SIGEANSUD : tracer chaque repas d'un parc animalier

Une solution complète pour un parc animalier : une application Android pour les soigneurs, un back-office pour les gestionnaires et une API REST Symfony 7 qui relie les deux.

  • Java · Android
  • Symfony 7
  • API REST
  • MySQL
  • UML

Le besoin

Le parc animalier SIGEANSUD gérait l'alimentation de ses animaux à la main. Impossible de savoir rapidement qui avait nourri quel animal, à quelle heure et en quelle quantité. Le parc voulait une traçabilité complète pour suivre la santé des animaux et organiser le travail des soigneurs.

La solution de l'équipe

  • Application mobile : les soigneurs saisissent en temps réel l'heure et la quantité des repas donnés aux espèces dont ils ont la charge.
  • Back-office web : les gestionnaires administrent les soigneurs, affectent les espèces, définissent les menus et consultent l'historique.
  • API REST Symfony 7 : une couche métier unique qui fournit les données au mobile et au web.

Ma contribution : l'application Android

  • Maquettage des écrans et des parcours, pensés pour le terrain : saisie rapide, peu de manipulations.
  • Développement natif en Java sous Android Studio : saisie d'un repas, animaux par espèce, menus du jour et historique des repas.
  • Intégration de l'API REST : récupération des menus et envoi des repas saisis.
  • Accès filtré : chaque soigneur ne voit que les espèces qui lui sont affectées.

Méthode et livrables

  • Modèle organisationnel des traitements (MOT) validé avec l'équipe pédagogique.
  • Spécification de l'API, diagrammes UML (classes, séquences) et MCD.
  • Plans de tests avec jeux de données, documentation utilisateur.
  • Suivi Agile des tâches sur Trello.

Ce que j'en retiens

Faire communiquer un client mobile avec une API m'a appris à raisonner en contrat d'interface : se mettre d'accord sur les routes et les formats avant de coder, pour que le mobile et le back-office avancent en parallèle.
