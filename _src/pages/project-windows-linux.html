Projet BTS SIO · AP0

Monter une infrastructure Windows & Linux

Un réseau d'entreprise simulé de bout en bout : domaine Active Directory, serveur web sous Debian, VLAN et services DNS/DHCP. Un projet côté infrastructure qui m'aide aujourd'hui à comprendre où tournent mes applications.

  • Windows Server
  • Debian
  • Active Directory
  • Cisco
  • VLAN
Contexte
BTS SIO — AP0
Durée
2 mois
Focus
Sécurité et disponibilité
Mon rôle
Administration système et réseau

L'objectif

Mettre en place un environnement réseau professionnel : Windows Server pour la gestion des utilisateurs et des postes, Linux Debian pour les services web, le tout segmenté et sécurisé.

Réalisations

  • Contrôleur de domaine Active Directory sous Windows Server, intégration des postes clients.
  • Serveur web Apache sous Debian, relié au domaine.
  • Segmentation en VLAN et routage inter-VLAN simulés sous Cisco Packet Tracer.
  • Configuration DNS et DHCP, règles de sécurité.
  • Tests de connectivité et vérification de l'isolation entre sous-réseaux.

Ce que j'en retiens

  • Penser la sécurité dès l'architecture, pas après coup.
  • Administrer un domaine : utilisateurs, groupes, stratégies (GPO).
  • Configurer et maintenir un serveur Linux.
