Projet BTS SIO · AP3

Une application web pour une fédération de triathlon

Clubs, licenciés, compétitions, inscriptions, dossards et résultats : une application sécurisée qui centralise l'organisation des triathlons.

  • PHP · MVC
  • MySQL
  • Merise
  • JavaScript
  • Git
Contexte
BTS SIO SLAM — AP3
Durée
2 mois
Équipe
4 étudiants
Mon rôle
Conception, base de données, développement

Le besoin

La fédération (FFTRI, dans le scénario du projet) devait disposer d'une application web sécurisée pour gérer ses compétitions, ses clubs et ses licenciés, avec deux profils d'utilisateurs.

Gestionnaire fédéral

  • Clubs, catégories d'âge, types de triathlons
  • Création et publication des compétitions
  • Inscriptions et attribution des dossards
  • Saisie des résultats par épreuve

Responsable de club

  • Gestion de ses licenciés
  • Suivi des inscriptions
  • Consultation des résultats de ses athlètes

Ma contribution

  • Cahier des charges : besoins fonctionnels, contraintes techniques, périmètre et livrables.
  • Schéma de navigation : parcours utilisateur et enchaînement des pages.
  • Base de données : MCD Merise, schéma MySQL et jeux de données de test représentatifs.
  • Développement PHP/MVC du tableau de bord administrateur et de l'espace licencié.

Contraintes respectées

  • Architecture MVC et conventions de nommage communes à l'équipe.
  • Authentification obligatoire : application réservée à la fédération et aux clubs.
  • Aucune fonctionnalité livrée sans tests fonctionnels validés.
  • Travail en Scrum/Kanban sur Trello, code partagé avec Git.

Ce que j'en retiens

Concevoir la base de données en premier a évité beaucoup de retours en arrière : un MCD solide rend le développement des écrans presque mécanique. J'ai aussi appris à découper le travail pour que quatre personnes avancent sans se bloquer.
